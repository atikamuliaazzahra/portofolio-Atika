# Atika Mulia Azzahra — Personal Portfolio

Website portofolio statis menggunakan HTML, CSS, dan JavaScript, sesuai alur tugas profil pribadi.

## Struktur
- `index.html` — struktur halaman
- `style.css` — tampilan dan responsivitas
- `script.js` — menu mobile, animasi reveal, navigasi aktif, dan tahun otomatis
- `assets/` — tempat menyimpan foto profil

## Cara menjalankan
1. Buka folder ini di VS Code.
2. Tambahkan foto profil ke folder `assets` dengan nama `foto-profil.jpg`.
3. Buka `index.html` di browser atau gunakan ekstensi Live Server.
4. Ganti alamat email dan username GitHub contoh di bagian Contact pada `index.html`.
5. Ganti konten pendidikan, pengalaman, dan kartu project contoh dengan informasi asli.

## Deploy ke Vercel
Ini adalah website statis, jadi tidak membutuhkan build command atau framework.
1. Push semua file project ke repository GitHub.
2. Masuk ke Vercel dan pilih **Add New → Project**.
3. Import repository GitHub yang berisi website.
4. Untuk project HTML statis, gunakan pengaturan default yang sesuai static site; jika diminta, biarkan Build Command kosong dan gunakan root directory project.
5. Klik **Deploy**, lalu buka domain `.vercel.app` yang diberikan Vercel.

## Checklist sebelum dikumpulkan
